# Notifications

## Channels

- In-app notification centre
- Transactional email
- Optional daily summary for non-urgent activity

## Required events

- Manager invitation
- Viewer email verification
- Password reset
- MFA or security change
- Manager scope assignment or removal
- Submission assigned for review
- Submission approved and published
- Changes requested
- Submission rejected
- Mention or review comment
- Project/action deadline approaching
- Import completed or failed
- Account locked, suspended, or restored

## Behaviour

Every notification links to an authorised destination. If access has been removed, the destination must not expose record information.

Notifications should contain enough context to act but must not place restricted evidence or personal data in email. Duplicate updates should be grouped, and users should be able to mark items read.

Security and invitation emails cannot be disabled. Product notifications may support preferences later.
