# Xpro web architecture

This folder describes the frontend currently implemented in `resources/ts`. It is
an implementation reference for the customer, provider and staff browser app.

- [Frontend structure](frontend-structure.md) covers bootstrapping, layouts,
  modules and the request path through the UI.
- [Routes and access](routes-and-access.md) covers public pages, workspaces,
  authentication and the current API boundary.
- [Operations state and workflows](operations-workflow.md) covers the demo state,
  command pipeline, projections and approval gates.

The [product flow](../flows/xpro-frontend-ui.md) describes the user journeys.
The [web and server auth plan](../api/auth-web-server-plan.md) tracks integration
work. Architecture here describes present behavior; the auth plan describes work
still needed.
