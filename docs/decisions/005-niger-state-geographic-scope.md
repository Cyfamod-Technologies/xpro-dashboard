# ADR 005: Niger State Geographic Scope

- **Status:** Superseded by ADR 007
- **Decision:** Scope the first release to Niger State, Nigeria, while keeping country explicit in stored records for interoperability.

## Consequences

- Geography uses configurable Niger State LGA and community hierarchies.
- Currency and fiscal year are explicit.
- Nigeria and Niger State are the interface defaults.
- Manager scope includes LGA, Program, or Project.
- Any geographic expansion requires a superseding architecture decision. ADR 007 records that expansion.
