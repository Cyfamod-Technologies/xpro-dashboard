# ADR 003: Admin Publication Approval

- **Status:** Accepted
- **Decision:** A Super Admin must approve information before it becomes visible to Budget Viewers.

## Consequences

- Managers cannot publish.
- Review snapshots and decisions are audited.
- Viewer data is derived from approved versions.
- Changes requested or rejected do not affect the current public version.
- Future reviewer roles may extend the support chain, but final publication authority remains explicit.
