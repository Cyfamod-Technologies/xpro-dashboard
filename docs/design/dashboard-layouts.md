# Dashboard Layouts

## Shared structure

1. Page title and current context
2. Global filters
3. Attention/next-action panel
4. Summary metrics
5. Primary chart or map
6. Detailed tables
7. Recent activity or updates

## Super Admin dashboard

- Submissions awaiting review
- Oldest pending submission
- Pending Manager invitations
- Locked or suspended users
- Published records by period
- Recent high-risk audit events
- Import failures and data-quality warnings

## Manager dashboard

- My drafts
- Changes requested
- Submitted items
- Assigned Programs and Projects
- Records missing source/evidence
- Action and outcome deadlines
- Allocation totals in assigned scope
- Recent publication decisions

## Budget Viewer dashboard

- Approved allocation total with currency and fiscal-year context
- Published project count
- Allocation by Program, location, agency, sector, and year
- Tracking-status distribution
- Projects requiring action
- Recently verified updates
- Geographic coverage

Every metric must link to a filtered list and clearly identify the data period. Mixed currencies are displayed separately unless a documented conversion basis is selected.
