# Accessibility

The target is WCAG 2.2 AA for core journeys.

## Requirements

- Keyboard access for navigation, filters, forms, dialogs, tables, and approval controls
- Visible focus indicators
- Proper headings, landmarks, labels, and error associations
- Status text/icons in addition to colour
- Sufficient contrast using approved tokens
- Screen-reader announcements for validation, loading, publication, and import progress
- Logical focus after navigation and modal closure
- Accessible chart summaries and downloadable tables
- Touch targets appropriate for mobile use
- Reduced-motion support
- No essential instruction conveyed only through position, colour, or hover

Automated checks support but do not replace manual keyboard and screen-reader testing of signup, login, project submission, approval, and viewer exploration.
