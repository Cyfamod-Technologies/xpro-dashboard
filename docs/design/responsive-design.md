# Responsive Design

## Breakpoints

Use the existing design system breakpoints consistently. Validate at compact mobile, large mobile, tablet, laptop, and wide desktop sizes.

## Behaviour

- Sidebar becomes a drawer on compact screens.
- Filter bars collapse into a filter sheet while preserving active-count badges.
- Tables provide priority columns, horizontal scroll, or card views without hiding critical status.
- Charts have readable summaries and do not require hover.
- Form wizards use one-column sections on mobile.
- Review comparisons stack current and proposed values on narrow screens.
- Primary actions remain reachable without covering content.
- Upload progress survives drawer/dialog layout changes.

The MVP is online-only but should remain usable on mobile and slow networks. Avoid loading large map, chart, or file-preview bundles until needed.
