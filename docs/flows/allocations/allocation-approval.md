# Allocation Approval

Super Admin review must show:

- Previous and proposed amount
- Absolute and percentage change
- Currency and fiscal year
- Budget source and agency
- Reference/source evidence
- Project context
- Submitter note
- Data-quality warnings
- Viewer preview

Large changes may trigger a warning threshold but not an undocumented automatic rejection. The Super Admin approves and publishes, requests changes, or rejects with a reason.

After publication, dashboards, totals, search filters, and exports must use the same approved allocation projection.
