# Assign Program Managers

1. Super Admin opens a Program and selects **Manage access**.
2. Admin searches active Managers.
3. UI shows each Manager's existing state and LGA scopes.
4. Admin assigns a responsibility level and effective date.
5. Backend prevents assignment outside valid LGA scope unless the admin explicitly expands that scope.
6. Assignment is audited and Manager is notified.

Removing the last Manager warns about unowned drafts, projects, and submissions. Those responsibilities must be transferred or marked intentionally unassigned.
