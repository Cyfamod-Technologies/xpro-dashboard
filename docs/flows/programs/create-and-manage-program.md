# Create and Manage Program

## Create

1. Authorised Manager or Super Admin selects **New Program**.
2. User enters name, unique code, summary, objectives, Nigerian state coverage, start/end dates where applicable, status, and responsible Managers.
3. User may add donor/funding metadata without creating donor access.
4. System validates code uniqueness and assigned scope.
5. Record is saved as draft and submitted for Super Admin approval when it will affect viewer-facing classification.

## Program detail

The page shows overview, Nigerian state coverage, Managers, tracked projects, allocation totals, status distribution, donors/funding metadata, files, and history.

## Lifecycle

```text
DRAFT -> ACTIVE -> INACTIVE -> ARCHIVED
```

Archiving is blocked while active projects require reassignment or resolution. Archived programs remain searchable to authorised staff and preserve public project links.
