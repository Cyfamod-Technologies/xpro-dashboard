# Manager Submission

Managers may submit valid program, project, allocation, evidence, action, or outcome revisions within scope.

1. UI runs a readiness checklist.
2. Manager reviews the viewer preview and changed fields.
3. Manager adds a submission note.
4. Backend validates the complete aggregate and creates a review snapshot.
5. State becomes `SUBMITTED`.
6. The item appears in the Super Admin queue and notifications are sent.

The submission records author, base version, timestamps, scope, proposed visibility, and related evidence. Draft validation errors remain actionable and do not erase form data.
