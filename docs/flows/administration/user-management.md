# User Management

Super Admins can search users by name, email, role, state, country, program scope, and invitation status.

## Actions

- Invite Manager
- Inspect Viewer registration and verification state
- Resend or revoke invitation
- Assign or remove Manager scopes
- Trigger password reset
- Reset MFA with reason
- Lock, suspend, restore, or archive
- Revoke one or all sessions
- View account security and administrative audit history

Role promotion to Super Admin is a high-risk action requiring recent authentication, explicit confirmation, and audit. Viewer-to-Manager promotion should use the Manager onboarding flow so scope and MFA are completed.

The list must not display secrets, password data, MFA seeds, or full recovery codes.
