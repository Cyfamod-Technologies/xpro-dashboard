# System Configuration

Super Admin configuration includes:

- Default country (Nigeria), default state (Niger), state/LGA/community reference data, currency, fiscal-year labels, and location types
- Programs and program status options
- Agency types
- Project sectors and status vocabulary
- Allocation sources and classifications
- Evidence type, size, and visibility rules
- Take Action types
- Notification templates
- Import templates
- Registration, MFA, and session policies

Every configuration change requires validation and audit. Options already referenced by records should be deactivated rather than deleted. Changes that alter public labels or workflow behaviour should show impact before confirmation.
