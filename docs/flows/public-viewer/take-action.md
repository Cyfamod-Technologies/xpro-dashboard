# Take Action

## Purpose

Take Action helps viewers respond to a published project issue. It is a call to engagement, not a completion state.

## Possible MVP actions

- Share the project
- View approved contact or agency guidance
- Submit structured project feedback
- Report an observed status with evidence, if enabled
- Follow the project for approved updates

Only action types approved for the project are shown. If viewer submissions are enabled, they enter a moderation queue and do not change public project status automatically.

Sensitive personal details must not be requested without a defined need and privacy rule. Success feedback explains what happens next and does not promise an outcome Xpro cannot guarantee.
