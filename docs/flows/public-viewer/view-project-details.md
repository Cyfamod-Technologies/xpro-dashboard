# View Project Details

The viewer detail page presents the current approved version only.

## Sections

- Project title, status, Program, fiscal year, and last verification
- Plain-language description
- Nigerian state, LGA, and approved location hierarchy
- Responsible agency
- Allocation table with currency, source, and references
- Approved public evidence
- Approved timeline/status updates
- Take Action panel when applicable
- Related approved projects

The page must not expose internal identifiers unnecessarily, draft state, review comments, private upload paths, or restricted metadata. A stable public identifier supports links even when a later version is published.

If a project is archived, the page explains its state and displays the last approved information according to retention policy.
