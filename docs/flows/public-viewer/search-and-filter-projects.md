# Search and Filter Projects

Viewers can search approved projects by title, reference, agency, Program, or location.

## Filters

- Country
- State/province and lower administrative areas
- Program
- Fiscal year
- Sector
- Responsible agency
- Tracking status
- Allocation range and currency
- Action required
- Last verified date

Filters are encoded in safe query parameters for sharing and browser navigation. Results show title, location, Program, fiscal year, approved allocation, status, last verified date, and action indicator.

Sort options include relevance, newest verification, allocation amount, and title. Export uses the same approved filters and displays export preparation time and currency context.
