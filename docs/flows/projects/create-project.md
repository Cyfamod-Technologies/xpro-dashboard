# Create Project

## Preconditions

The Manager has project-management permission within the selected Program and country.

## Steps

1. Select **New Tracked Project**.
2. Select Program and optional Campaign.
3. Enter title, description, sector, fiscal year, source/reference, and responsible agency.
4. Confirm the default country (Nigeria), select a state (Niger by default), and enter an LGA or configured location.
5. Add implementation and tracking status.
6. Add one or more allocations.
7. Add source evidence and proposed viewer visibility.
8. Add Take Action information if action is required.
9. Review validation summary.
10. Save draft or submit for approval.

## Validation

The system checks required fields, scope, valid location hierarchy, fiscal year, currency, non-negative amounts, source references, possible duplicates, and public-evidence classification.

## Completion

Saving creates a draft invisible to Budget Viewers. Submission locks the review snapshot while allowing a controlled withdrawal before review starts.
