# Complete and Archive Project

## Completion

1. Manager records the outcome or formal closure reason.
2. Manager uploads supporting evidence and updates tracking status to proposed `OUTCOME_VERIFIED` or `COMPLETED`.
3. Manager submits the revision.
4. Super Admin reviews outcome evidence and public wording.
5. Approval publishes the verified outcome and completion status.

Reaching Take Action or publishing a project is not completion.

## Archive

Archival occurs after completion or an approved formal closure. The system warns about open actions and pending revisions. Archived projects leave active work queues but retain stable history and approved viewer access according to policy.
