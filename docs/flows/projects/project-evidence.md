# Project Evidence

## Add evidence

1. Manager selects project draft/revision and chooses **Add evidence**.
2. Manager uploads a permitted file or provides an approved source URL.
3. Manager enters title, description, evidence type, capture/source date, location where relevant, source, and proposed visibility.
4. Backend validates size, type, content safety, ownership, and scope.
5. Evidence remains attached to the draft and unavailable to viewers.
6. Super Admin reviews evidence and visibility with the containing submission.

## Viewer publication

Only evidence included in an approved version and classified for viewer access receives viewer-safe metadata and authorised download/view access.

Replacing or removing published evidence creates a new revision. Internal notes, private identities, banking information, unverified allegations, and restricted material cannot be exposed through viewer APIs or predictable file URLs.
