# Evidence Fields

- Evidence ID
- Parent Project/version
- Evidence type
- Title
- Description
- Original and safe display filename
- Media type and size
- Storage reference
- Checksum
- Upload/processing status
- Source or capture date
- Uploader
- Country/location where applicable
- Source URL where applicable
- Proposed and approved visibility
- Review status and reviewer
- Created/updated timestamps

Storage references and malware-scan details are never sent to Budget Viewers. Viewer metadata excludes personal or restricted fields. File access requires a current authorization decision rather than a permanent predictable URL.
