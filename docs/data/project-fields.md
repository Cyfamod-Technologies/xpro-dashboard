# Project Fields

## Identity

- Stable internal ID
- Public ID
- Program and optional Campaign
- Project reference/code

## Versioned content

- Title
- Plain-language description
- Sector/category
- Fiscal year
- Budget/source reference
- Country, Nigerian state or FCT, LGA, and locations; defaults are Nigeria and Niger
- Responsible agencies
- Tracking status
- Implementation notes
- Last verified date
- Public summary
- Take Action content
- Proposed visibility

## System metadata

- Draft owner
- Base version
- Revision number
- Approval status
- Published version pointer
- Created/updated/submitted/approved/published timestamps
- Created by, submitted by, approved by

Required fields may vary by Program template, but public title, Program, country, fiscal year, location context, source, status, and at least one valid allocation/source relationship should be addressed before publication.
