# Terminology

| Term | Meaning |
| --- | --- |
| Program | A continuing Xpro initiative that organises related Nigerian state projects |
| Campaign | An optional time-bound operational effort within a Program |
| Tracked Project | A government-funded public project being monitored and presented through the platform |
| Allocation | A budget amount assigned to a Tracked Project for a fiscal year and funding source |
| Agency | The ministry, department, agency, or public institution responsible for a project |
| Evidence | A document, photograph, source link, or observation supporting project or outcome information |
| Action | An advocacy or engagement activity related to a Tracked Project |
| Take Action | A viewer-facing call to engage; it is not the same as project completion |
| Revision | A proposed replacement for an approved record version |
| Submission | A draft revision formally sent to a Super Admin for review |
| Published Version | The approved immutable version visible to Budget Viewers |
| Public Data | Data explicitly approved for Budget Viewer access |
| Internal Data | Operational data available to Managers and Super Admins only |
| Restricted Data | Sensitive information available only to explicitly authorised users |
| Outcome Verified | Evidence of an outcome has been reviewed and approved |
| Completed | A tracked outcome is achieved, verified, or formally closed—not merely published |
| Source of Truth | The authoritative system whose approved version controls what the product displays |

## Avoided ambiguity

“Project” must mean Tracked Project in viewer-facing screens. Internal software delivery work should be called a task, ticket, or release to avoid confusion.

“Budget” in the MVP means public government project allocation information. It does not mean Xpro payroll, staff expenses, banking, procurement, or confidential internal finance.
