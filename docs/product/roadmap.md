# Roadmap

## Phase 1: Foundation

- Xpro branding and cleaned dashboard shell
- Viewer signup and email verification
- Manager invitation
- Login, password recovery, MFA, and session management
- Role and scope guards
- Super Admin user management
- Nigerian state, LGA, and location reference data, with Niger as the default
- Audit and notification foundations

## Phase 2: Source-of-truth workflow

- Program management
- Tracked Project creation and revisioning
- Allocation management
- Evidence upload and visibility classification
- Manager submissions
- Super Admin review, changes requested, approval, and publication
- CSV import and validation

## Phase 3: Viewer experience

- Budget overview
- Project search and advanced filters
- Allocation charts and tables
- Geographic exploration
- Project detail pages
- Take Action presentation
- Exports and saved views

## Phase 4: Outcome and operational maturity

- Action progress and outcome verification
- Completion and archival
- Advanced reporting
- Data-quality dashboards
- Configurable approval support chain
- Donor-scoped approved reporting

## Later updates

- Offline PWA field capture
- Additional roles
- Identity provider and accounting integrations
- Anonymous public pages
- Advanced GIS
- Automated anomaly and risk detection

Each phase must preserve the invariant that Budget Viewers only receive approved public versions.
