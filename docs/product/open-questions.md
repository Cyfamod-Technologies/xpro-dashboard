# Open Questions

The core architecture is approved. The following implementation details still require product or operational confirmation.

## Product and data

- Which Xpro program will be configured first?
- Which fiscal years and project datasets will be imported first?
- Will Budget Viewer registration allow any verified email or block disposable email providers?
- Is anonymous public access planned, or will all viewers require an account?
- Which allocation sources and budget classifications must be represented?
- Can a Tracked Project have multiple implementing agencies?
- Can one allocation fund more than one location?
- What evidence types may be public by default, if any?
- Which Take Action options should be available in the first release?
- What exact evidence qualifies an outcome as verified?

## Administration

- How many Super Admins must exist before launch?
- May a Super Admin approve content they authored, or is a second Super Admin mandatory?
- How are Manager LGA and program scopes assigned and reviewed?
- What is the retention period for archived users and records?

## Design

- Which current dashboard components are licensed for continued production use?
- Which map provider and geographic data source will be used?

## Integration

- Which email provider sends invitations and verification messages?
- Where will evidence files be stored?
- Is CAPTCHA required at launch?
- Which analytics and error-monitoring services are approved?

These questions should not block documentation or basic scaffolding. They must be resolved before the affected feature is accepted for production.
